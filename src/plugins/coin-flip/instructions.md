# Coin Flip Simulation

Flip a coin many times and watch what happens to the fraction that come up heads. This is the **Law of Large Numbers** in action.

## Read the code

Look through the starter code and find where `random.choice` is used. That line is what flips the coin — it randomly picks `"H"` or `"T"` each time through the loop.

## Fill in the blank

Fill in the blank on line 1 (check the last slide for a hint on what to import).

## Run it

Set `total_flips` to a whole number greater than 10 so you can see the pattern, then run the code. Try `50`, then `500`, then `5000`.

## Think about it

- What happens to the blue line as you add more flips?
- Does it get closer to the target line at `0.5`? Why might that be?

## You did it!

You flipped a coin thousands of times and watched the fraction of heads settle toward `0.5, which is the **Law of Large Numbers** in action. The more flips you added, the closer the proportion hugged the target line. Over many trials, randomness averages out to what probability predicts.
